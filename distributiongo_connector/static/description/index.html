DistributionGo Connector

Connect Odoo deliveries to DistributionGo warehouse picking and the SortingGo App.

What it does

DistributionGo is a free warehouse-execution system: it turns reserved deliveries into picking tasks for warehouse staff working with the SortingGo App on phones and tablets, then ships the picked quantities back into Odoo. This module is the narrow connector DistributionGo calls through Odoo's JSON-2 API.

  • Order pool: outgoing deliveries that Odoo has fully reserved, searchable and paged.
  • Snapshot: one call returns a delivery's lines, quantities, locations and a version, all from the same moment.
  • One write method: applies a pick result to a delivery in a single Odoo transaction and stores a receipt under the caller's operation key. Sending the same key again returns the stored result instead of shipping twice, so a lost network answer never causes a double shipment.
  • Short picks: the rest of a delivery becomes a backorder or is dropped, as DistributionGo asks.
  • Route check: shows which warehouses use a delivery route DistributionGo serves.

Safe by design

  • Runs as the calling user (a dedicated DistributionGo bot), never with sudo().
  • Everything is read-only except the one write method above.
  • Makes no outbound connections and stores no addresses: DistributionGo calls Odoo, never the other way round. Access is granted by the bot's API key and revoked by deleting it.
  • Depends on the Community module stock only.

Requirements

  • Odoo 19.0, self-hosted or on Odoo.sh. Odoo Online cannot install custom modules and is not supported.
  • One-step deliveries (warehouse delivery route "Deliver goods directly").
  • DistributionGo 2.0 or later.

Setup

  1. Install this module (DistributionGo Connector).
  2. Create a user for DistributionGo, for example dg-bot, with only these rights: Internal User, Inventory / User and DistributionGo Connector.
  3. Signed in as that user, create an API key (My Preferences, API Keys). Odoo 19 asks for an expiry date.
  4. In DistributionGo, set the Odoo address, the database name and that API key (DG_ODOO_URL, DG_ODOO_DB, DG_ODOO_KEY) and restart its services.
